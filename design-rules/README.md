# Sanawbar Design Rules

This directory is the source of truth for Sanawbar interface patterns. Read the relevant rule before changing UI code, then implement the pattern through the shared component named by that rule.

## Rules

- [Empty states](empty-states.md) — empty collections, filtered results, unavailable content, and recovery actions.

When a new recurring visual or interaction pattern is approved, document it here before duplicating it across pages. Rules supplement the Arabic-first, component-reuse, conflict, accessibility, and security requirements in `AGENTS.md`.
