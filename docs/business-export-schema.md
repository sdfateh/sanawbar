# Business export v7: column dictionary

The ZIP contains only SQL. This external dictionary maps each short destination table and column to its source business record and field. The mapping is fixed in `sanawbar/business_export/schema.json`; new source fields are never included automatically. All SQLite columns have TEXT affinity. A missing allowed source column becomes SQL NULL.

Every table uses `id` for the original document identifier and `state` for document status (0 draft, 1 submitted, 2 cancelled). Child tables use `parent_id`, `parent_tbl`, `bucket`, and `seq` for parent ID, neutral parent table, neutral collection, and position. Enumerated document-type reference values become neutral table names. The source field names below are documentation only; exported SQL uses the destination aliases.

Each table also has `raw_refs`: NULL normally, or a JSON object preserving original reference spellings when MariaDB resolves a spelling variant to an existing target ID. Object keys are destination column aliases. Original document IDs are never changed. Landed-cost `pur_rcpt_item` references a vendor-bill line when its receipt kind is `vendor_bills`, or a goods-receipt line when it is `goods_receipts`; use the exact aliases below for the discriminator and reference columns.
